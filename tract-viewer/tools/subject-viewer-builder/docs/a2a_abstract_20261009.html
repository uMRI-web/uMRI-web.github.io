拡散MRI情報を用いた標準白質路アトラスの個人T1強調MRI上への変形と教育用Web Viewerへの実装

学会抄録風作業記録　2026年10月9日

【目的】

通常診療で広く撮像されるT1強調MRI上で白質路の位置を把握しやすくするため、同一被験者の拡散MRIから得られたfractional anisotropy（FA）画像を解剖学的位置合わせの媒介として用い、標準白質路probabilistic atlasを個人T1強調MRI上へ変形する手法を試作した。さらに、深層学習による脳領域自動分割結果と統合し、白質路と関連解剖領域を同時表示する教育用Web Viewerを構築した。

【方法】

既に研究・教育目的で公開している同一被験者のT1強調MRIおよびDTI由来FA画像を使用した。まずNIfTIヘッダ情報を確認し、旧データに存在したqform/sform等の幾何情報の不整合を修正した。個人FA画像をFMRIB58 FA標準画像へ線形位置合わせした後、FNIRTによる非線形変形を行い、その逆変換を作成した。JHU white-matter tractography atlas由来のprobabilistic tract mapをこの逆変換により個人FA空間へ移し、さらに個人FA画像と個人T1強調MRI間の剛体変換を用いて個人T1空間へ変換した。錐体路、視床前放線、上縦束、側頭部上縦束、下前頭後頭束、下縦束、鉤状束、帯状束、脳梁線維等、計20本の左右別または正中白質路を対象とした。

個人T1強調MRIにはSynthSegを再適用し、1 mm isotropicのT1画像およびparcellationを生成した。そこから各白質路に関連する皮質・皮質下構造を抽出し、既存Viewerと同様にCOREおよびLANDMARKとして構造化した。白質路probability map、5% threshold mask、脳領域mask、および3D meshを作成し、2D三方向断面と3D表示を同期させたWeb Viewerへ実装した。

【結果】

FA画像から標準FA空間への非線形位置合わせ、および逆変換による標準白質路アトラスの個人FA空間への投影は良好に行われた。さらにFA-T1変換を介して、白質路probability mapを個人T1強調MRI上へ表示可能であった。20白質路について個人T1空間上のprobability mapを作成し、左右統合画像を含め計29画像を生成した。SynthSegによる個人脳parcellationから77の解剖学的ROIを抽出し、白質路、CORE、LANDMARK、および3D脳表を同時表示するWeb Viewerを構築した。代表白質路について目視確認を行い、T1画像、白質路および関連ROIの位置関係に明らかな破綻を認めなかった。

【結論】

個人DTI由来FA画像を標準白質路アトラスと個人T1強調MRIとの橋渡しに用いることで、標準白質路情報を個人T1画像上へ変形し、深層学習による脳領域分割結果と統合して可視化できた。本手法は個人の真のtractographyを再構成するものではないが、通常のT1強調MRI上で「白質路がどのあたりを走行するか」を理解するための教育用ガイドとして利用できる可能性がある。今後は複数例での再現性評価、atlas deformation単独法との比較、およびT1画像のみから白質路ガイドを推定するAIモデルとの比較を行う予定である。
