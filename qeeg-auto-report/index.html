qEEG 自動レポート

日本光電 Neurofax EEG-1200 / EEG-1290 からASCII形式でエクスポートした .m00 を解析し、Wordレポートを生成します。

データは外部サーバーへ送信しません。
解析はこのページを開いているPCのブラウザ内だけで実行されます。GitHubにも患者データは保存されません。
解析エンジンを準備しています…

既存解析の信号処理・Z-score表示値を94例で検証した互換実装です。Fp1=左、Fp2=右として左右表記を修正し、トポグラフィーは各帯域の正しいZ-scoreを使用します。研究・検証用であり、診断を自動確定するものではありません。

初回はPython / NumPy / SciPy / Matplotlib等をブラウザに読み込むため時間がかかることがあります。
